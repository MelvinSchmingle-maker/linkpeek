# DeArrow: Firefox Add-ons reviews

Collected 17 Oct 2026 from Mozilla's public reviews API (https://addons.mozilla.org/api/v5/ratings/rating/?addon=dearrow&page_size=50&page=1 to 5).
Sample: 128 reviews with written text, out of the 250 most recent ratings (pages 1 to 5 of the API), dated 6 Feb 2024 to 8 Oct 2026. Stars: 26 one-star, 10 two-star, 11 three-star, 17 four-star, 64 five-star.

Ranked with `reviews.py` from [replica-skill](https://github.com/Jakeschincariol/replica-skill) (MIT), with extra themes for extensions (wrong results, false alarms, missed threats, privacy, permissions, crowd submissions). Every quote is copied from a review and links to it. All reviews come from one source, so the tool marks every theme "thin" by its own rule. Read the counts as "within Firefox reviewers", not as a market finding. Theme matching is by keyword and is noisy: some quotes sit under the wrong heading. The hand counts in `../competitors-2026-10.md` were checked by reading the matches.

The raw review text is not kept in this repo. Run the API URL above to get it again.
