Each row says where its result came from. "Live" means the real extension, on a real public page, run from a cloud machine through its proxy on 17 Oct 2026. Its output is in `docs/compat/part-04-live.md`, or in the four extra runs noted below. "Fixture" means one of LinkPeek's test pages, served locally and labelled as made up. A row marked "not run" was not checked, and nothing is claimed for it.

Screenshots: the browser tests save screenshots of every card state for light and dark themes in `docs/screenshots/`. No screenshots were taken of the live rows, so none is claimed here (`docs/compat/screenshots/` is empty for that reason).

Judgements of whether a summary is accurate were made by reading the output, not by a person who knows the story. They say so where they're made.

## Notes on this matrix

- Row 2 is a real failure found by these runs. It's not fixed here, because a fix means recognising listing pages in extraction, which is bigger than the plan's "fix small bugs" scope. It's in `open-issues.md`.
- Rows 10 and 11 are not the same test: there's one YouTube page, and no page without a transcript was run separately.
- Row 19 went from "not covered until Part 11" to covered.
- The live rows use the 17 Oct run. Re-run `node scripts/build.mjs --live && node scripts/live-check.mjs` before relying on any of them, because sites change.
